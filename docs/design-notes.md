# AFTERWAKE — Design Notes

このゲームは `yz4git/game-core` に蓄積された設計知見をもとに、短いブラウザー向けアクションとして新規に組み立てたものです。特定作品のキャラクター、世界設定、ステージ、文章、画像、固有ルールは再現していません。

## 核となる判断

敵はコアへ向かう。プレイヤーは移動して一時的な軌跡を描き、敵が線を横切ったときにタグが付く。移動距離で溜まるパルスをいつ使うかが、主な判断です。一本の軌跡で複数の敵を横切ると、位置取りとタイミングが同時に報われます。

## 反映した設計方針

- **入力を絞り、結果を広げる:** 移動とパルスの2入力で、軌跡の形・敵の進路・起爆時刻を選びます。
- **予測できる脅威:** 通常敵はコアへ進み、突進敵はオレンジの線で進路を予告します。最終攻撃は安全な切れ目を持つ衝撃波です。
- **短い学習ループ:** 最初の敵は単純な直進型で、最初の数秒にタグ付けとパルスを試せます。失敗後はすぐ再挑戦できます。
- **失敗の因果を示す:** 敵の侵入、接触、タグ、起爆、コア損傷を色・形・動き・短い音で伝えます。色だけには頼りません。
- **速度でなく要求判断を増やす:** セクターが進むと敵数、突進の組み合わせ、同時に監視する方向が増えます。
- **成功後の呼吸:** セクター間には短い間を設け、コアの回復と次の波の予告を行います。
- **再挑戦の第二目標:** 固定の5セクターをクリアした後も、ベストスコアと最大チェーンの更新を目指せます。
- **スマホ向け入力:** 左側ドラッグで移動、右側の大きなPULSEボタンで起爆します。HUDはsafe-area内に置き、操作指で中心の脅威を隠しにくくしています。
- **決定論的な遭遇:** セクター構成と敵の移動規則は固定し、結果を覚えたうえで軌跡と起爆を改善できます。
- **短い反復UI:** 効果音の切替、一時停止、再挑戦はゲーム画面から一手で行えます。

## 最初の検証項目

1. 初見でも10秒以内に移動とPULSEの役割が分かるか。
2. 1本の軌跡で複数の敵をタグ付けする成功が自然に起きるか。
3. 起爆が早すぎた／遅すぎたことを見て理解できるか。
4. 突進敵と衝撃波が、予告から回避・起爆の判断につながるか。
5. タッチ中に親指が敵やコアを長時間隠していないか。
6. セクター突破に失敗しても、同じ低密度区間を長くやり直さずに済むか。

この一式は最初のプレイ可能版です。実機のタッチ感や難易度曲線は実プレイで確認して調整する前提です。
